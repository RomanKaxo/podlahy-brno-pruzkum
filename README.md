# Podlahy Brno — průzkum trhu

Veřejná analytická stránka o epoxidových a polyuretanových podlahách v Brně a okolí. Podklady byly kontrolovány 12. října 2026.

Obsahuje konkurenční profily, klíčové fráze, veřejné cenové příklady, jednorázové snímky vyhledávání, metodiku a interaktivní model reklamního rozpočtu.

## Datová omezení

Jde o cílený průzkumný vzorek, nikoli úplný soupis trhu. Hledanost a skutečné CPC nebyly získány. Reklamní rozpočty a kalkulačka jsou výslovně plánovací scénáře, ne prognóza počtu zakázek. Veřejné nabídky firem nejsou nezávislé hodnocení kvality.

## Web

Statické HTML/CSS/JavaScript bez závislostí. GitHub Pages publikuje větev `main` z kořenového adresáře. Datové přílohy jsou v `data/`.

Lokální náhled lze spustit standardním statickým HTTP serverem. Zdroje tvrzení jsou odkazované přímo na stránce a v datových přílohách.
